This room needs a Supabase project before it can store accounts and messages. Open web/config.js in the repository, paste in your project URL and anon key, then commit and push.

Both values are in your Supabase dashboard under Project Settings → API.

window.CHAT_CONFIG = {
  SUPABASE_URL: 'https://xxxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGci...',
};
